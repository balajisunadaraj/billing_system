# Metal Plate Inventory & Billing Management System

A React + Tailwind frontend with a Node.js + Express backend using PostgreSQL.

## Features

- Dashboard with inventory, revenue, and pending bills
- Company management (add / edit / delete)
- Purchase entry module with waste tracking
- Delivery entry module with stock validation
- Invoice generation and bill history
- Office settings for invoice branding
- Reports and export-ready UI

## Setup

1. Copy `.env.example` to `.env`
2. Update `DATABASE_URL` and `PORT` as needed
3. Run `npm install`
4. Start backend: `npm run server`
5. Start frontend: `npm run dev`

## Tech stack

- Frontend: React, Tailwind CSS, Vite
- Backend: Node.js, Express, PostgreSQL
